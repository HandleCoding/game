# 2026-10-04 牧场资源加载画面（v2.5.2）

## 行为
读取存档时显示准备画面；获得动物清单后，按实际必要资源的图片加载与 decode 完成数更新百分比及“已就绪 / 总数”。资源为草地背景、工具图集、当前场景所需动物图集；不为首屏预加载全部36种图鉴。进度不是下载字节比例，也不是计时模拟。
首帧 Canvas 绘制后才揭开加载画面并显示 HUD / 工具栏 / 动物选择；加载中可以返回大厅。资源网络失败或解码失败显示原地重试，25秒无响应提供重试，已经解码成功的图片保留。退场取消本组件待加载任务，防止完成回调影响已退出的游戏。动物成熟或购买需要新图集时使用同一加载流程；原生详情面板在加载新资源时暂时隐藏，加载完成后恢复原选择和面板，确保重试入口可操作且不打断认养流程。
RanchLoading.vue 为统一自适应界面，图形内联SVG，无新增外部素材。后端只改版本号；游戏规则、资源数值、数据库和存档不改。

## 开发验收
云端 /opt/pair-play-dev；随机开发schema、3221与flock锁，未写正式测试账号。
- npm run typecheck / npm run build：退出0。
- scripts/ranch-loading-qa.mjs：Chromium22项、WebKit20项，全部通过。存档准备、延迟背景时非假100%进度、首屏资源裁剪、就绪前隐藏工具、首帧绘制、网络失败/损坏PNG重试、保留成功资源、退出并再次进入、浏览器无未捕获错误。
- Chromium额外覆盖真实等待25秒超时及恢复；WebKit没有重复该25秒场景。
- 390×844、1440×1000、844×390的加载面板尺寸检查；手机/电脑截图实际查看。截图 artifacts/ranch-loading/{chromium,webkit}。
- 有缓存的图像可直接完成，不强制显示一个计时动画。失败验收使用新文档/冷图片请求，避免已解码图像让模拟网络错误不再触发；测试过程中修正了这个测试条件，最终报告为通过结果。
- 现有牧场交互回归 Chromium / WebKit 各五组、共十组（320/390/430竖屏、844横屏、1440桌面）全部通过。认养时面板选择在新资源完成后恢复；开发中发现并修复了提前关闭商店的问题。报告 ranch-loading-ui-{chromium,webkit}.json。不把模拟视口说成实体手机。
