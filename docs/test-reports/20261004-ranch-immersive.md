# 沉浸式牧场 2.3.0 验收（2026-10-04）

## 最终变更

用户参考微信小程序的体验，要求进入牧场后场景铺满屏幕、功能浮在场景边缘，而不是网页中的图片卡片。已实现独立 100dvh 游戏视口、安全区、浮动身份 / 等级 / 资源、边缘菜单、底部六项工具、日夜切换，以及支持时的用户点击浏览器全屏。玩法说明改成原生 dialog；商店、仓库、喂食、串门和详情继续独立弹窗。

## 验收期间修正

1. 第一轮横屏食槽标签与底栏接近，实际截图还发现离线提示、动物选择条重叠：调整横屏独立位置，并新增 DOM 矩形不相交断言。
2. 初次 WebKit 390px 的 900ms 单帧对比不能稳定捕捉缓慢待机变化：改为 5 秒内实际 Canvas 内容发生变化，仍验证暂停 / reduced-motion 完全静止；最终所有尺寸通过。
3. 移动端食槽在 pointerup 打开面板，后续兼容 click 可能点到新面板的“+100”，测试截图发现多买一轮：场景先记录点击目标，到完整 click 时才打开 dialog。增加网络动作断言，确认每个用例只有一笔 buyFeed、数量为显式选择的 20，两个浏览器最终通过。
4. 食槽实体使用 Canvas 点击检测；仅标签使用 DOM 按钮，避免透明大区域挡住场景拖动。
5. 参观时清空 panel，避免旧面板在新牧场上方残留。

实际截图 artifacts/ranch-ui/{chromium,webkit}/ 下，已将 Chromium 的 390 手机、844 横屏、1440 电脑截图取回 Windows 并查看。测试账号均为随机隔离 schema 中的虚拟验收账号。
