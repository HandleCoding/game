# 一起牧场：首版 36 种动物与数值

更新：2026-10-04（Asia/Shanghai）。用户要求首版至少 30 种，按不同等级解锁、不同成长与生产时间；已设计 36 个不同物种，而非将幼崽与成年重复计数。

## 资料核验与设计来源

已读取 QQ 经典农场官方微博近期公开内容（https://www.sina.cn/media/8466618130），其中 2026-09-09 萌宠活动说明有比熊幼崽养至成年、宠物养成与装扮。公开公告未提供可核验的新版完整牧场 30+ 动物价格、成长、生产数值表，故本表不能标成新版官方数值。

历史参考为 https://github.com/Boldcc/qqfarm/blob/master/upload/home/qqfarm/source/mc/config/animal.php （通过 GitHub API 实际读取）。其中鸡成熟 8 小时 / 间隔 6 小时、兔 10 / 8、羊 15 / 12、鹅 9 / 7、牛 18 / 12、猫 19 / 9。此处前六类对应时间按约“旧版一小时→本作 30 秒”缩短，保留层次；解锁顺序、其余物种、货币、经验、产量与文案由本项目独立设计。没有复制旧 PHP 代码、私有接口或腾讯素材。

## 首版规则

- 初始 800 金币、160 份饲料、4 个位置和一只带 3 份产物的成年小鸡。
- 每只每分钟吃 1 份饲料，共用食槽，上限 1000 份；缺粮暂停成长，不死亡。
- 每只最多保留 3 轮产物，超过容量不继续堆积；按服务器时间离线结算。
- 每 80 经验升一级；认养经验为 8+解锁等级，收获每份经验为 4+floor(解锁等级/4)。
- 每轮出售收入约为认养价的 26%，各物种取整数，第一只鸡最低单价 12；出售成年动物返还实际购入价 60%，幼崽 30%，须先收净产物。
- 宠物 / 野生动物主要提供纪念章等游戏收藏品；界面为卡通养成设定，不模拟真实动物采集。
- 扩建每次 +2 个位置，4→16。费用从 300 开始，每次加 200。
- 动物实例保存生长周期、产出周期、单轮产量、产物、实际买入价与收获经验，后续改商店参数不追溯修改已有动物周期。
