## 场景融合

- 原牧场背景、左侧食槽及木牌保留。图集采用相同的暖色左上光、略俯视三分之四视角及草地反射色，不自带阴影 / 地面 / 外描边。
- scripts/analyze-soft-ranch-atlas.py 只读 alpha，生成 soft-atlas-metadata.ts 的真实行边界、共同裁切框、各帧脚底基线；不修改 PNG 像素。Canvas 保持身体原比例，不再把长身体动物强行拉成正方形。
- sprites.ts 用服务端 a.baby 选择独立阶段图；每种体量由 animalExtent 定义，鸡兔较小、牛马大，长颈鹿和大象更大。游戏内体量是可玩性压缩比例，不是动物学 1:1。
- RanchScene.vue 按纵深缩放并以脚底落地，统一绘制柔和橄榄色接触阴影和右下方向散射阴影。待机呼吸 / 步态起伏幅度减小；喂食轻微晃动，暂停和减少动态效果保留。
- 初始站位增加间距并错开行；超过 7 只时按平方根密度适当缩小整体体量，减少大动物遮住后排。触控命中按身体大小且保留最小触控范围；重叠时优先选择前景动物。状态提示跟随实际身体高度。
- 场景按现有动物阶段加载需要的图集；幼年成长为成年时按需补加载。AnimalPortrait.vue 共用边界；详情显示当前阶段，商店展示成年外观，购买仍得到幼崽。
- 物种 ID、解锁、价格、成长 / 产出 / 饲料规则和存档完全沿用服务端。没有 schema 迁移，没有重置玩家动物。

## 验收方式

云端 npm run typecheck / build 和 npm run test:ui，独立 playroom_dev schema / 3221 锁；Chromium / WebKit 各五组尺寸。新增独立幼年图加载检查、禁止旧 cartoon 图请求。390px / 1440px 另用浏览器拦截的公开视图夹具展示所有物种与两阶段及混合牧场；夹具只用于视觉检查，不写正式库。PNG 透明通道与所有帧非空由只读分析器验证。截图必须实际检查；模拟浏览器不代表实体手机或微信真机。
