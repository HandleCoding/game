# 山间牧场：三维场景体验小样

体验地址：https://game.aicoding.ltd/ranch-3d/

云端源码：`/opt/pair-play-dev/prototypes/ranch-3d`。这是独立的视觉和交互原型；正式牧场仍是游戏大厅中的一起牧场。版本 0.1.0，不接账号、数据库、SSE、金币、生产或变异规则。

## 本次验证的方向

- 草地、路径、房屋、树、围栏、池塘、食槽和三个动物均为真正的三维网格。没有背景 PNG，没有动物图片、billboard 或 CSS 平移来冒充三维。
- 小鸡、垂耳兔、山羊使用可转动的身体、头和腿；走动、呼吸、耳朵、尾巴和吃食由骨架式对象层级驱动。采用简化的原创程序模型，不代表最终美术品质。
- 同一 WebGL 渲染器、相机、世界坐标、深度缓冲和灯光。树、围栏与动物互相遮挡，动物投影落在地面，树影也会落在动物身上。
- 草叶实例化和风摆、真实水面网格及涟漪、昼夜灯光过渡和夜间灯笼。
- 选择动物、近景、全景、喂食、暂停；拖动旋转、滚轮缩放、触屏双指控制由 OrbitControls 提供。
- 幼年预览采用缩小身体并放大头部比例。尚未制作每个物种独立的幼年解剖、毛发、材质、动作和成长模型。
- 加载进度对应实际场景构建与 shader 编译阶段，不是按秒虚增的进度，也不是资源字节下载百分比。WebGL 初始化失败和 context lost 显示重新进入按钮。

## 技术与运行

TypeScript + Three.js 0.186.1 + Vite 7，依赖锁文件固定实际安装版本。保留现有 Vue/Fastify/PostgreSQL 架构；Three.js 仅负责这个独立展示模块，不新增一个后端。

在京东云运行：

```sh
cd /opt/pair-play-dev/prototypes/ranch-3d
npm ci --no-audit --no-fund
npm run check
npm run build
```

Vite base 为 `/ranch-3d/`。`dist` 和 `node_modules` 不提交。服务只提供 `dist` 静态文件；不能把整个开发目录作为静态根目录。Caddy `/ranch-3d/*` 使用 `handle_path` 去掉前缀，其余路径继续进入原 3210 服务；`/ranch-3d` 308 重定向到尾斜杠地址。Caddy 已验证并 reload，未重启应用或 PostgreSQL。修改前备份在 `/var/backups/pair-play/caddy-ranch-3d-20261005-103637.conf`。

无需 Windows Node 进程、localhost 转发或登录即可访问小样。全部代码依赖已打包，体验时不下载 npm/CDN、图片或外部字体。

## 文件与扩展边界

| 文件 | 职责 |
| --- | --- |
| main.ts | 场景、网格地形、灯光、相机、移动、喂食、加载与交互 |
| models.ts | 三个物种的程序网格、对象层级、共享几何与材质 |
| index.html / style.css | 覆盖在场景上的响应式操作区 |
| vite.config.ts / tsconfig.json | 独立编译，子路径发布 |

正式接入时应保留现有后端规则与权限，仅让场景接收公开/主人可见的 RanchView，按永久 animalId 建立展示对象。点击收获/喂食仍向平台发送现有后端动作，不能让浏览器决定资源、时间和变异结果。

正式美术应另做统一视角、体量、材质的 glTF/GLB 动物模型，独立幼年/成年模型及动画片段，减少 draw call，按需加载。以这份小样验证的一体光照、遮挡、相机和空间关系为基准；是否用 Three.js 或 Cocos 做最终场景还未锁定。当前全是简单模型，不应宣称实现了柔和写实毛发、72个精细生命阶段、完整寻路或所有移动设备性能验收。

## 验收

详见 `../../docs/test-reports/20261005-ranch-3d-prototype.md`。通过云端类型检查和构建，实际浏览器检查电脑 1440×900、手机 390×844 / 360×780 与横屏 844×390。手机为浏览器尺寸模拟，真实手机硬件、微信内置浏览器和双指触控仍需用户实机体验。
