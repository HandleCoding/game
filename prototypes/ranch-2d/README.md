## 视觉方向

用户喜欢已有的柔和写实动物和背景画风，拒绝程序化简化 3D 动物，也拒绝仅给单一背景图加阴影。此样品保留原动物图集；把场景组织为可单独排序、碰撞、互动的二维物件，不改变动物身份和画风。

地面与远景仍使用绘制素材。这是二维游戏的美术载体，不意味着树、围栏和食槽只烘焙在一个背景里。树、食槽、围栏、门均为独立物件，画面依足底坐标前后排序。远景有视差，树有轻微风动/摇叶，动物有足底接触阴影、轮廓投影、局部草叶遮挡和随树荫变化的柔和色调。

“平面对照”是同一小样关闭这些效果后的对照，不是生产版本截图。

## 代码分工

- main.ts：场景物件、演示状态、镜头、资源队列、指针操作及渲染循环。
- scene-blending.ts：按真实图集边界截取动作帧，缓存渲染帧、接触点、轮廓阴影、光照和草叶。只做运行时 Canvas 合成，不覆盖原始美术文件。
- action-atlas.ts / public/actions/manifest.json：成年/幼年共24个吃食姿态，按实际透明间隙分帧，统一身体锚点和脚底；深低头姿态嘴/喙位置逐种核对，用于食槽接触点。
- feeding.ts：两侧独占食位、先进先出等待、抬头后离位再放行；不改变真实耗粮或成长规则。
- navigation.ts：四邻域 A* 和圈/矩形碰撞。围栏两端覆盖可行走边界；关门阻断通路，开门重算目的地路径。
- sprites.ts / soft-atlas-metadata.ts：复用原动物图集索引及足底/裁切元数据。
- public/scenery：本小样独立场景素材，新增独立草叶随风摆动、近距离步行带动弯曲、遮挡树根/围栏落地处。树冠与树干分区渲染，风动不旋转树根。初版生成记录见 ASSET-PROMPTS.json，本轮见 ASSET-V2.json。

## 资源与开发

依赖已在本云端目录安装。操作命令：

    cd /opt/pair-play-2d-dev/prototypes/ranch-2d
    npm ci --no-audit --no-fund
    npm run check
    npm test
    npm run build

dist 被忽略，Caddy 静态读取该目录。不要在共享工作树切换分支、安装依赖或覆盖正式版本。若要另开开发实例，请使用独立端口，勿占用 3210/3211。

原动物和工具图集从同域 /ranch/scene/soft/ 和 /ranch/ui/ 公开静态路径读取，正式资源目录保持不变。首次加载使用两路队列和下载/解码进度，每路 45 秒无数据则中止，出错显示重试；动画尚未就绪时不会出现空草地。手机控制像素比例并约 30fps，桌面约 60fps。

## 验收与限制

导航自动校验包含关门不可穿过、开门可通过、绕过树干/食槽、路径段不穿障碍。浏览器实测记录见 QA.md。

这是方向验证，只有小鸡、垂耳兔、山羊的原成年和幼年形象；已补独立低头/啄食/抬头姿态、移动距离驱动步伐、加速和减速、近距离足底避让与绕行。两只同时吃食，其余等候；嘴部接触槽内饲料，离开一定距离后让位。选中动物优先，动画暂停时不推进排队或吃食。

仍未实现全部36种的互动动作、八方向转身、睡眠、池塘交互、昼夜天气、生产UI和牧场经济数据接入。4个生成姿态仍为有限帧动画，不是连续骨骼；足底避让不等于全身体碰撞，相邻身体可能自然遮挡。道具阴影仍为近似投影，复杂树枝与动物身体的遮挡还需细化。不要将本演示说成正式牧场全部完成。

## 后续合并

先由用户比较小样与线上画面，确认方向。合并时保留另一分支的品质、变异、寿命、收获等规则，以场景渲染器接口读取动物身份/生长阶段/位置；真实购买、饲料和收获继续由后端验证。合并时继续使用最新 appearance.ts 的 materialFrame / drawAttributeAura，保留 attributes 双属性和品质展示；原图的足底坐标和透明裁切用于投影，属性材质再叠加树荫。小样展示普通动物，不模拟新的变异抽取或合成。将导航物件与美术分开配置，继续补充房屋、池塘和交互动作，优先替换现有场景渲染层，避免重新实现牧场 API。

## 本轮素材复现
保留新动作图和草叶PNG原图，同时提供无损WebP；四张图经解码RGBA逐像素相等核验，仅改变编码格式。原站立/行走图集及正式资源不改。
analyse-actions.py只读PNG透明通道并输出JSON，不生成或裁切图像文件；需要Pillow和numpy。行列边界按实际透明间隙找出，不假定图集均分；深低头嘴部坐标来自人工检查。运行时Canvas统一锚点后绘制，防止切图串入相邻动物。
